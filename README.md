# GoBasics

Este repositório está sendo criado para registrar meu aprendizado na linguagem Go.

Aqui vou reunir exercícios, exemplos práticos, pequenos projetos e anotações conforme avanço nos estudos. O objetivo é praticar os fundamentos da linguagem e acompanhar minha evolução.

O conteúdo será atualizado aos poucos, com novos estudos e descobertas.

## Estudos

- **FirstServer**: primeiro servidor HTTP com `net/http`, rotas, respostas em texto e tratamento de erros.

## Como executar

Com Go instalado, execute na pasta principal do repositório:

```sh
go run FirstServer/main.go
```

Abra <http://127.0.0.1:8080> no navegador. Para encerrar o servidor, pressione `Ctrl + C` no terminal.

## Organização

Cada novo estudo pode ficar em sua própria pasta, com seus exemplos e anotações.
